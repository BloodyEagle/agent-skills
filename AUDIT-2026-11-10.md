## Часть 2. План исправлений (рабочий документ для агента)

Правила для исполнителя:
1. **Один пункт = один коммит** (или тесно связанная группа). Стиль репо: сообщения на русском, без зависимостей, только node stdlib / stdlib python.
2. **Перед началом**: `git checkout -b fix/audit-2026-11-10`. **После каждого пункта**: `node skills.js verify` + релевантный selftest/тест + добавь регресс-тест в соответствующий selftest/сьют.
3. Самтесты: php `node .../bx.js op=selftest` (38), ts `op=selftest` (17) + `node --test` в `tests/token-economy-ts`, kt `op=selftest` (22), java `op=selftest` (12), har `node --test tests/token-economy-har` (29), CLI `node --test test/`. Финал: `node --test` из корня (105) — все зелёные.
4. Общий паттерн для трёх «системных» багов, найденных в нескольких скиллах: **(а) скобочные матчи `< 0` → не зацикливаться**; **(б) `fs.realpathSync` на входной путь перед проверкой «внутри корня»**; **(в) ограничение длины входа для бэктрекинг-регулярок**.

### Батч 1 — P0 (порча данных)

- [ ] **1.1 php: фикс бесконечного цикла на атрибутах.**

  Проверка: `parsePhp()` на файле с `#[ORM\Column]` перед свойством — не съедает память, класс/методы видны; в selftest добавить кейс «атрибут на члене класса» и «атрибут на классе»; прогнать на копии `tests/token-economy-php/laravel-app`.
