# Компактный JSON

Перед использованием `--compact` или декодированием compact-ответа прочитай этот файл.

## Включение и fallback

`--compact` — opt-in для `--json`; с `--pretty` он несовместим. Команда возвращает либо документ `har-compact-v1`, либо обычный legacy JSON, если компактная форма не короче, ответ пуст/диагностический либо относится к `help`/`redact`. Обрабатывай обе формы. `--compact` не меняет отбор, сортировку, лимиты, счётчики, коды завершения и не очищает секреты.

Compact строится из уже ограниченного legacy JSON. После декодирования результат ему глубоко равен, но режим не восстанавливает данные, уже отсутствующие из-за legacy-лимитов. `truncated`, `omitted`, `omittedValues`, `omittedIndices` и другие признаки неполноты сохраняют прежний смысл.

## Envelope

```json
{"format":"har-compact-v1","data":{"command":"slow","total":2,"shown":2,"omitted":0,"truncated":false,"items":{"columns":["index","method","url","timings"],"rows":[[0,{"$ref":0},{"$prefix":[0,"a"]},[0,null,3,1,0,8,2]]] }},"timingColumns":["blocked","dns","connect","ssl","send","wait","receive"],"strings":["GET"],"urlPrefixes":["https://example.test/"]}
```

В конкретном ответе присутствуют только фактически использованные схемы и словари.

- `data` — legacy payload после обратимых преобразований.
- Таблица `{columns, rows, defaults?}` заменяет однородный список объектов. Каждая строка сопоставляется с `columns`; затем в объект добавляются `defaults`. Отсутствующее поле нельзя подменять `null`.
- `timingColumns` задаёт порядок массива фаз. Значения не округляются и не вычисляются заново; `null` и `0` различаются.
- `headerColumns:["name","value"]` задаёт строки заголовков/query. Стороны, порядок, повторы, регистр и пустые значения сохраняются.
- `endpointColumns` задаёт массивы `before`/`after` в `diff`; `null` endpoint остаётся `null`.
- `strings` разрешает только тег `{"$ref":N}`. Обычное число не является ссылкой.
- `urlPrefixes` разрешает только тег `{"$prefix":[N,"suffix"]}`; исходный URL равен буквальной конкатенации. Префиксы не нормализуют URL.

Декодируй в таком порядке: ссылки/префиксы, таблицы/defaults, массивы фаз и пар, endpoint `diff`. Проверяй границы индексов, длины строк и отсутствие неизвестных тегов. Не используй схемы из прошлого вызова: каждый tagged-документ самодостаточен.

Compact не кодирует тела, значения заголовков или query через словари и не минифицирует захваченный текст. Перед передачей ответа другому человеку или агенту действуют те же правила очистки, что и для legacy JSON.
