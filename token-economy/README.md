Скилл для экономии токенов.

Скилл написан для kilocode - секция в самом начале SKILL.md, ограниченная `---` обязательна для этого агента, без нее он не увидит скилл.

Скрипты написаны для запуска через Node.js, но можно переписать на любой язык, как вам удобнее.

Скрипты скилла:

| Действие | Что делает | Экономия                                  |
|---|---|-------------------------------------------|

Скрипт state-manager - реализация SKILL.state (https://arxiv.org/abs/2608.26263) - работает только на длинных сценариях, от 15 шагов.
