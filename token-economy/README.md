Скилл для экономии токенов.

Скилл написан для kilocode - секция в самом начале SKILL.md, ограниченная `---` обязательна для этого агента, без нее он не увидит скилл.

Скрипты написаны для запуска через Node.js, но можно переписать на любой язык, как вам удобнее.

Скрипты скилла:

| Действие | Что делает | Экономия                                  |
|---|---|-------------------------------------------|
| `git-check` | Список файлов с незакоммиченными правками; стоимость не зависит от объёма правок | Стартовая карта состояния за ~400 токенов |
| `compress` | Срезает комментарии и форматирование | Вход сжимается в 2–3 раза                 |
| `search` | Поиск: имена файлов, номера строк, сниппеты | 50–90% против чтения файлов               |
| `outline` | Оглавление файла: классы, методы, номера строк | ~10% объёма файла                         |
| `schema` | Только интерфейсы и типы без логики | 60–80%                                    |
| `api` | HTTP-вызовы: URL и сигнатуры без реализаций | 60–80%                                    |
| `deps` | Граф импортов: кто импортирует файл и что он импортирует | Замена грепа по репозиторию               |
| `diff` | Статистика + изменённые строки без контекста | Зависит от объёма правок                  |
| `patch` | Точечная замена фрагмента | До 90% выходных токенов на правке         |
| `generate` | Обёртка над CLI фреймворка | ~100% выходных токенов на шаблонном коде  |

В папке скриптов есть еще скрипты, которые были в 1-й версии, но в моем случае давали оверхед всместо экономии. Если кому пригодится - отлично!

Скрипт state-manager - реализация SKILL.state (https://arxiv.org/abs/2608.26263) - работает только на длинных сценариях, от 15 шагов.
