# Экономия токенов (скилл token-economy)

    Первым действием в любой задаче вызывай git-check из скилла token-economy — получи список файлов с незакоммиченными правками.
	Навигацию выполняй через graph-операции скилла: определения символов и селекторов (op: symbol/selector), зависимости и потребителей файла (op: deps/rdeps), связи файлов (op: path). search и чтение файлов — только для деталей реализации.
    Чтение файлов, поиск, анализ и все правки выполняй только инструментами скилла token-economy. Пороги применимости (размер файла, объём правок)описаны в SKILL.md — следуй им.
    Тебе строго запрещено перезаписывать файл целиком, когда по порогам скилла применим patch (правки менее 30% файла).
    Сущности Angular (компоненты, сервисы, пайпы, модули, директивы,гварды) создавай только через generate, заготовки руками не пиши.
    Перед патчем файла из списка git-check сначала прочитай его актуальнуюверсию инструментами скилла: oldChunk должен соответствовать текущему состоянию файла, а не последнему коммиту.
    Не запускай компиляцию, линтер, тесты, полный билд и ng serve — об ошибках я сообщу сам.
