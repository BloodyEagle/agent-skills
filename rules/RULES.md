# Код

- Angular не ниже версии 15.
- Строгая типизация: без `any`, явные типы возврата, ранние возвраты вместо вложенных условий.
- Переменные, функции, методы, свойства — camelCase. Классы, интерфейсы, enum и типы — PascalCase (так их создаёт Angular CLI). Файлы — kebab-case по соглашению CLI.
- JSDoc пиши только для публичного API (классы, методы, интерфейсы): краткое описание + `@param`/`@returns`. Примеры использования — только по моему запросу.

# Порядок работы с кодом (обязательный)

Навигация, поиск и создание сущностей — ТОЛЬКО через скилл token-economy по стеку проекта: TypeScript / Angular / Angular — token-economy-ts (search / outline / graph / generate), PHP / 1С-Битрикс — token-economy-php, Java / Spring Boot — token-economy-java, Python — token-economy-py. Синтаксис команд: .kilocode/skills/<имя-скилла>/SKILL.md — открой перед первой командой сессии.
Штатные инструменты — только Read и точечные правки. Отступление — только с моего разрешения.

## Выбор источника

- Где определён символ, селектор, пайп, переменная или миксин; кто использует файл; что он использует; как связаны два файла — `graph` (op: `symbol` / `selector` / `deps` / `rdeps` / `path`).
- Детали реализации — чтение файла.

## Навигация и чтение

- Перед правкой общего файла (сервис, модель, пайп, общий миксин или переменная стилей) вызови `graph` (op: `rdeps`) — узнай, что заденет правка.
- Вопрос «используется ли компонент / директива / пайп» — `graph` (op: `selector`, затем при необходимости `rdeps`).
- `search` — для мест использования текста. Для html и стилей передавай `ext` (`.html`, `.scss`, `.less`, `.css`).
- Файл меньше 300 строк читай напрямую. Файл от 300 строк — сначала `outline`, затем Read(offset, limit) нужного диапазона.

## Правки

- Файл длиннее 50 строк при правке менее 30% — только точечная замена штатным инструментом. Перезаписывать файл целиком запрещено.
- Перед правкой прочитай актуальную версию нужного фрагмента: заменяемый текст должен совпадать с текущим состоянием файла.
- Сущности Angular (компоненты, сервисы, пайпы, модули, директивы, гварды) создавай только через `generate`, заготовки руками не пиши.

## Запреты

- Встроенный поиск агента (search_files / grep / ripgrep) не используй никогда: в проекте есть строки длиннее 64 КБ, на которых он обрывается. Весь поиск — только search скилла.
- Не читай .ts-файл от 300 строк целиком: сначала outline, затем Read(offset, limit).  Размер файла заранее — graph (op: node, поле loc).
- Не пиши вручную заготовки сущностей: component, service, pipe, directive, guard, module, interface, enum, class, resolver, interceptor — только generate.
- Команды скилла вызывай только `node "<путь>\<скрипт>.js" ключ=значение…`; параметры через пайп/stdin не передавай; не используй `|`, `;`, `&`, `$()`, backtick, `>` — они запрещены правами среды.
- Команда скрипта упала — почини (путь до скрипта, кавычки, значения аргументов) и повтори. Подменять скрипт встроенным поиском или чтением целиком запрещено. Не выходит — спроси меня.
- Использования с учётом тестов — graph со specs=true.
- Не запускай компиляцию, линтер, тесты, полный билд и `ng serve` — об ошибках я сообщу сам.
- Не читай файлы `graph-deps.json` и `.graph-deps-cache.json`: только ответы операций `graph`.
