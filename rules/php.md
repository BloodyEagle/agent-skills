# PHP — token-economy-php

- Стек: любые PHP-проекты — 1С-Битрикс (старое API до D7 и D7), Laravel, MODX; если CMS не определена — универсальный режим. Скрипт `bx.js`.
- Один раз за разговор, прежде чем читать или править файлы, вызови `info`: режим проекта, кодировки, состав файлов.

## Кодировки (cp1251)

- Если `info` показал файлы в cp1251, любые файлы с кириллицей читай только операцией `read`, правь только `patch`, создавай только `create`. Штатные инструменты чтения и записи портят cp1251 (кириллица превращается в мусор, и файл ломается).
- `search` находит кириллицу и в cp1251 — им и ищи.

## Правки

- Точную замену фрагмента делай через `patch`: он сохраняет кодировку (UTF-8 / cp1251), BOM и переводы строк (CRLF / LF).
